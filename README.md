# Emacs Config

My minimal GNU Emacs configuration for **C#, C++, C, JavaScript, and TypeScript**.

The goal is to keep Emacs simple, lightweight, and productive with only the essential tools needed for everyday development.

## Features

- Minimal configuration with no unnecessary customization.
- Eglot for Language Server Protocol (LSP) integration.
- Magit for Git version control.
- Support for C, C++, C#, JavaScript, and TypeScript.
- Keyboard-driven workflow.

## Philosophy

Keep the configuration simple and understand every customization instead of relying on a prebuilt configuration framework.

## Setup

1. Install GNU Emacs.
2. Clone this repository.
3. Apply the configuration to your Emacs setup.
4. Install the required language servers and development tools for your languages.

## Status

Work in progress. The configuration will evolve as I learn Emacs and identify tools that improve my workflow.
